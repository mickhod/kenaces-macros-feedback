# kenace’s Macros Feedback

Use this repository to report bugs and suggest improvements for **kenace’s Macros**, a client-side Minecraft mod for chat and command macros.

## Submit feedback

- [Report a bug](https://github.com/mickhod/kenaces-macros-feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/mickhod/kenaces-macros-feedback/issues/new?template=feature_request.yml)
- [Browse existing issues](https://github.com/mickhod/kenaces-macros-feedback/issues)

Before opening an issue, search existing reports to see whether the same problem or idea has already been submitted.

## Reporting a bug

Use the bug report form and include:

- Minecraft version and mod version
- What you expected to happen and what happened instead
- Clear steps to reproduce the problem
- Screenshots, crash reports, or relevant log details when available

Please remove personal information, server addresses, access tokens, or other private details before attaching logs.

## Suggesting a feature

Use the feature request form to explain what you want to accomplish and how you would like it to work. A concrete example or use case helps make the suggestion easier to evaluate. Submit one main idea per issue so it can be discussed clearly.

## A few things to know

Kenace’s Macros runs on the Minecraft client. Server permissions, server plugins, and server-specific command or chat behavior can affect how a macro works. Please mention relevant server details in a bug report, without sharing private information.

Issues are reviewed as time allows. Reports and suggestions are welcome, though not every request can be implemented.
